# Enrica Sanitare — GitHub Pages website

1. Replace the placeholder contact details in `index.html`.
2. Replace the product placeholders with your real product photo(s).
3. Upload these files to a GitHub repository.
4. Enable GitHub Pages from Settings → Pages → Deploy from branch → main → /(root).
5. Add your custom domain in Settings → Pages → Custom domain.
6. Configure DNS at your domain provider.
